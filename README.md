# GHPC Music Controller

Choose between any of the 6 in-game battle music tracks in GHPC to play all the time, or play your own music in Gunner HEAT PC!

**Installation**

This mod requires MelonLoader 0.6.1.

Download the .DLL file from the latest release and put into your Mods folder in the game directory. Unzip the assets folder into that same folder. (THIS IS REQUIRED if you want to listen to Broken Arrow or Not One Step back). Instructions for how to set up your own music can be found inside MelonPreferences.cfg.

Run the game once to create a MelonPreferences.cfg file. In there you can pick what music you want to play.

Due to how Broken Arrow and Not One Step Back are accessed by the game, it is easier for loadtimes to simply load the music in from the mod assets folder. 

Sample Structure:

Bin/
├── Mods/
│   ├── GHPC_Music_Controller.dll
│   └── Music_Controller_Assets
|       └── Broken Arrow_L1.ogg
└── GHPC.Exe
